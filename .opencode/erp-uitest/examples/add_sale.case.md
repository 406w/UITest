# 新增销售订单并核对金额

CASE_ID: add_sale_from_text
TARGET: isolated

前置：使用管理员登录 ERP 隔离演示实例；存在客户“星河设计工作室”、仓库“上海主仓”和商品 P001/P002。

1. 进入销售订单页面，打开新增订单表单。
2. 客户选择“星河设计工作室”，仓库选择“上海主仓”。
3. 添加 P001，数量 2，单价 19.50 元；添加 P002，数量 3，单价 12.30 元；备注填写本次唯一 uitest-UUID。
   预期：表单合计为 75.90 元。
4. 保存订单，按本次唯一备注打开订单详情。
   预期：状态为草稿；客户、仓库、商品、数量、单价与输入一致，合计为 75.90 元。

恢复：只取消本次创建的草稿单，再退出登录。保留取消记录与审计日志，不重置演示库，不操作其他订单。
